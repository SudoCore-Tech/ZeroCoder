## What is ZeroCoder?

ZeroCoder is a community-driven application designed to help developers and students improve their coding skills, build a strong portfolio, and compete on a global leaderboard.

By connecting directly to your GitHub profile, ZeroCoder ensures that your real-world coding achievements are front and center.

## Key Features

* **Verified GitHub Profiles:** Log in with your GitHub account to sync your real developer identity.
* **Tasks & Challenges:** Complete coding tasks and submit your repositories for review.
* **Exams:** Test your knowledge with built-in, scheduled exams.
* **Earn XP & Level Up:** Gain experience points for approved tasks and passed exams to climb the leaderboard.
* **Community Driven:** See how you rank against peers in the SudoCore Tech community.
